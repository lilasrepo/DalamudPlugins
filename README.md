# DalamudPlugins（繁中服移植版）

這個 repo 提供可以在**繁體中文版 FFXIV** 的 Dalamud 上使用的插件。插件本身來自國際版（原作者的 repo），
我們把它們移植到繁中服目前的 Dalamud API 與遊戲版本，功能以原作者版本為準。

## 安裝

在 Dalamud 設定 →「實驗性功能」→「自訂插件存放庫」加入：

```
https://raw.githubusercontent.com/lilasrepo/DalamudPlugins/main/pluginmaster.json
```

存檔後到插件安裝器搜尋即可。本 repo 的插件名稱後面都會加上 `[TC api13]`，代表這是繁中服用的移植版，
以及它對應的 Dalamud API 版本。

## 怎麼看版本號

版本號的**前幾碼和原作者的國際版完全相同**，**最後一碼**則同時記錄了國際版的版本與繁中版的修訂次數：

```
最後一碼 = 國際版最後一碼 × 100 + 繁中版修訂序號
```

反過來讀：把最後一碼**除以 100**，整數部分就是國際版的最後一碼，餘數就是這個國際版本上的第幾次繁中修訂。

| 繁中版版號 | 對應的國際版 | 說明 |
|---|---|---|
| `2.1.0.1100` | `2.1.0.11` | 國際版 2.1.0.11 的第一個繁中版 |
| `2.1.0.1101` | `2.1.0.11` | 同一個國際版本上，繁中版多修了一次 |
| `7.5.6.900` | `7.5.6.9` | 國際版 7.5.6.9 的第一個繁中版 |
| `1.15.4.0` | `1.15.4.0` | 國際版最後一碼是 0 時，第一個繁中版號碼會和國際版一樣 |
| `1.15.4.1` | `1.15.4.0` | …之後的繁中修正從 1 開始往上加 |
| `15.700` | `15.7` | 只有兩碼的版本一樣是最後一碼 × 100 |

這樣做的原因：Dalamud 只在「新版號比已安裝的大」時才會提示更新。直接在國際版號碼後面 +1，會剛好撞上原作者的
下一個版本；用 × 100 的方式，繁中版的修正永遠有自己的號碼，而且國際版一更新，繁中版的號碼也一定跟著變大。

版本發佈頁的 tag 是 `v<版本號>-TC13`，`TC13` 代表 Dalamud API 13。

### 例外

- **還沒有新內容的插件**會保留舊的版號格式（例如國際版 +1），下次有更新時才會換成上面的規則。
- **AutoHook**：2026-09-23 的版號從 `5.1.0.4` 重設為 `5.0.0.5100`，讓它回到國際版的版號系統。版號變小了，
  Dalamud 不會自動更新，已經裝了 `5.1.0.4` 的人**請移除後重新安裝一次**，之後就會正常自動更新。
